# אתר ספרים לסופר

זהו אתר סטטי בעברית, מותאם למחשב ולנייד.

## קבצים

* `index.html` — תוכן האתר
* `styles.css` — עיצוב
* `script.js` — תפריט נייד והודעות טופס

## איך לפתוח

לחץ פעמיים על `index.html`, או העלה את כל התיקייה לשירות אחסון כמו:

* GitHub Pages
* Netlify
* Vercel
* Cloudflare Pages

## מה כדאי להחליף

1. `לירום משען`
2. שמות הספרים ותיאוריהם
3. כתובת הדוא"ל
4. קישורי הרכישה
5. קישורי הרשתות החברתיות
6. תמונת הסופר
7. כריכות הספרים

## חיבור טופס יצירת קשר

הטופס כרגע הוא הדגמה בלבד. אפשר לחבר אותו ל-Formspree, Netlify Forms או שירות דומה.
